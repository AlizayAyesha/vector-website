# Vector login + Stripe checkout spec (from Alizay's reference video, Cursor's flow)
Flow: pricing card button -> if signed out, go to login -> after login return to /upgrade?plan=X (plan review page) -> "Get <Plan>" opens an embedded Stripe checkout MODAL over the page (no redirect to a Stripe-hosted page).
Login page: solid dark background, small logo top-left, centered minimal box. Heading "Welcome to Vector" + one-line subtitle. Row of square grey provider icon buttons (Google, GitHub, Apple, SSO; only providers Vector's Supabase actually has enabled). "or" divider. One field "Your email address". Button "Continue with email" (outlined). Footer "Don't have an account? Sign up" + Terms link. No split screen or illustrations.
Pricing page: centered "Pricing", pill toggle Individual / Teams, plan cards side by side, highlighted plan has subtle border and SOLID white button, others outlined.
Checkout modal: dark, fade in, title "Checkout" with back arrow. Left: Monthly / Yearly selector (selected = blue border, show both prices), "Pay with" Apple Pay / Google Pay, "or", card number, MM/YY, CVC, Link checkbox, Billing information (country, "+ Add business details"). Right: plan name, price /month, "Due today", solid white "Subscribe & Pay". Implementation: Stripe Embedded Checkout or Payment Element; server creates the session/subscription with the secret key; webhook confirms; never trust the client.
